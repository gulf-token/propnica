## 1. Introduction

Propnica is a cloud-based SaaS platform designed for UAE real estate professionals to create stunning, cinematic property showcase videos featuring smooth map-based animations. Whether you are marketing a luxury villa on Palm Jumeirah or a commercial development in Dubai South, Propnica helps you create professional videos that highlight location, amenities, and surrounding areas.

### Key Features

- Smooth satellite map animations with customisable zoom levels
- Property boundary highlighting with animated polygons
- Animated route paths showing access roads and distances
- Professional overlays including logos, titles, and watermarks
- Multiple export formats optimised for social media platforms
- Cloud-based rendering for fast, high-quality output

## 7. Adding Keyframes

Keyframes define the camera positions throughout your video. The animation smoothly transitions between each keyframe.

### 7.1 Creating a Keyframe

1. Navigate the map to your desired view (position, zoom, bearing, pitch)
2. Click the "+ Keyframe" button or press `K`
3. The keyframe appears on the timeline

```
+------------------------------------------------------------------+
|  TIMELINE                                            [+Keyframe] |
+------------------------------------------------------------------+
|                                                                  |
|  Keyframe 1 (Selected)                                           |
|  +------------------------------------------------------------+  |
|  | Position:   25.2048, 55.2708 (Dubai Creek Harbour)         |  |
|  | Zoom:       15.5                                           |  |
|  | Bearing:    45 degrees                                     |  |
|  | Pitch:      60 degrees                                     |  |
|  | Time:       0:00                                           |  |
|  +------------------------------------------------------------+  |
|                                                                  |
|  0s      10s      20s      30s      40s      50s      60s       |
|  |                                                           |   |
|  [K1]                                                            |
|  +---+                                                           |
|  | * |  <-- Selected keyframe (gold highlight)                   |
|  +---+                                                           |
|                                                                  |
|  [Play] [Prev] [Next]              Total Duration: 0:45          |
|                                                                  |
+------------------------------------------------------------------+
```

### 7.2 Keyframe Properties

Each keyframe stores the following properties:

| Property | Description | Range |
|----------|-------------|-------|
| Position | Latitude and longitude of map centre | Coordinates |
| Zoom | Map zoom level | 0 (world) to 22 (building) |
| Bearing | Map rotation in degrees | 0 to 360 |
| Pitch | Camera tilt angle | 0 (top-down) to 85 (oblique) |
| Time | Position on timeline | 0 to video duration |

## 17. Troubleshooting

### Common Issues and Solutions

#### Map Not Loading

```
Problem: The map canvas shows a blank or grey area.

Solutions:
1. Check your internet connection
2. Refresh the browser page
3. Clear browser cache and cookies
4. Try a different browser (Chrome recommended)
5. Disable browser extensions that may block map services
```

#### Render Fails or Times Out

```
Problem: Video render fails to complete or times out.

Solutions:
1. Reduce video resolution (try 720p instead of 4K)
2. Shorten video duration
3. Reduce number of keyframes
4. Simplify overlays and elements
5. Check that your subscription has render credits remaining
6. Contact support if problem persists
```

#### Preview is Slow or Laggy

```
Problem: Preview playback is choppy or slow.

Solutions:
1. Use "Low" quality preview setting
2. Close other browser tabs
3. Use a device with more RAM
4. Reduce the number of overlays visible
5. Preview shorter sections at a time
```

#### Elements Not Appearing in Render

```
Problem: Polygons, routes, or markers missing from final video.

Solutions:
1. Check element visibility in Layers panel
2. Verify timing on Timeline (element may be hidden at that time)
3. Check element opacity is above 0%
4. Ensure element is within the map view area
5. Save project and re-render
```

#### Login Issues

```
Problem: Cannot log in to account.

Solutions:
1. Check email and password are correct
2. Use "Forgot Password" to reset
3. Clear browser cookies for properyclips.com
4. Try incognito/private browsing mode
5. Contact support with your registered email
```

### Getting Help

If you encounter issues not covered in this guide:

1. Visit our Help Centre at help.propnica.com
2. Email support at support@propnica.com
3. Use the in-app chat support (available during business hours)
4. Join our community forum for tips and discussions
